# 🏠 منصة الوسيط العقاري 

## وصف شامل للمشروع وميزاته

---

## 📌 مقدمة

منصة **الوسيط العقاري الذكي** هي نظام إدارة عقارية متكامل مبني بأحدث تقنيات الويب، يهدف إلى ربط ملاّك العقارات، المكاتب العقارية، مزودي الخدمات، والمشترين في منصة واحدة شاملة. تتيح المنصة إدارة العقارات من الإضافة وحتى البيع، مع نظام إعلانات متطور، محادثات فورية، حجوزات للمعاينات، اشتراكات مدفوعة عبر Stripe، نظام محاسبي مزدوج القيد، وإشعارات آنية عبر Pusher و FCM.

---

## ⚙️ البنية التقنية

| الطبقة | التقنية |
|--------|---------|
| لغة البرمجة | PHP 8.2+ |
| إطار العمل | Laravel 12 |

| الدفع الإلكتروني | Stripe |
| إدارة الطوابير | Laravel Horizon |
| توثيق API | Scribe |
| الحاويات | Docker (nginx, php-fpm, mysql, redis) |

## 🧱 هيكلة المشروع

المشروع مبني وفق نمط **الهيكلية المعيارية (Modular Architecture)**، حيث ينقسم إلى وحدات مستقلة، كل وحدة تحتوي على كل ما يخصها من متحكمات (Controllers)، خدمات (Services)، نماذج (Models)، طلبات (Requests)، موارد (Resources)، ومسارات (Routes). الوحدات هي:

```
Modules/
  ├── Auth/                ← المصادقة وإدارة المستخدمين
  ├── RealEstate/          ← العقارات والإعلانات والمعاينات
  ├── Communication/       ← المحادثات والإشعارات
  ├── ServiceProvider/     ← مزودي الخدمات
  ├── Subscription/        ← الاشتراكات والخطط والدفع
  ├── Ledger/              ← النظام المحاسبي
  └── Core/                ← الأساس (الدول، المدن، التصنيفات)
```

## 🔐 المصادقة وإدارة المستخدمين (Auth)

### تسجيل الدخول والخروج
- تسجيل مستخدم جديد (اسم، بريد، كلمة مرور).
- تسجيل الدخول عبر البريد الإلكتروني وكلمة المرور، ويعاد للمستخدم **Sanctum Token** للوصول للـ API.
- المصادقة الثنائية (Two-Factor Authentication) مدعومة بالكامل مع رموز استرداد.
- تأكيد البريد الإلكتروني عبر رابط تحقق.
- إعادة تعيين كلمة المرور عبر البريد الإلكتروني.
- تسجيل الخروج مع حذف جميع الرموز المميزة (Tokens).

### إدارة الملف الشخصي
- تحديث الاسم والبريد الإلكتروني.
- تغيير كلمة المرور (مع التحقق من كلمة المرور القديمة).
- رفع صورة شخصية (Avatar) وتخزينها بأنظمة متعددة الأحجام (thumb, medium).
- إدارة تفضيلات التواصل (داخل المنصة عبر المحادثة فقط / وسائل تواصل خارجية).

### أنواع المستخدمين والأدوار
- **مستخدم عادي (User):** يمكنه تصفح العقارات، إضافة المفضلة، بدء المحادثات، وحجز المعاينات.
- **ناشر (Publisher):** مستخدم يمتلك صلاحية نشر العقارات. ينقسم إلى:
  - **فرد (Individual):** شخص عادي ينشر عقاراته.
  - **مكتب عقاري (Office):** مكتب عقارات معتمد بعد تقديم طلب ترقية ومراجعته من الإدارة.
- **مزود خدمة (Service Provider):** مثل المصورين، المثمنين، المحامين، والمسوقين.
- **مشرف (Admin / Super Admin):** صلاحيات كاملة لإدارة المنصة.

### نظام الصلاحيات (Permissions)
يحتوي النظام على أكثر من **108 صلاحية** موزعة على 23 مجموعة، منها:

| المجموعة | الصلاحيات |
|----------|-----------|
| المستخدمين | عرض، إنشاء، تعديل، حذف، تغيير الحالة |
| الأدوار | عرض، إنشاء، تعديل، حذف، إسناد الصلاحيات |
| العقارات | عرض، إنشاء، تعديل، حذف |
| المعاينات | عرض، إنشاء، تأكيد، إلغاء، إعادة جدولة، إكمال |
| الإعلانات | عرض، إنشاء، تعديل، أرشفة، استعادة، تحليلات |
| الدول والمدن | عرض، إنشاء، تعديل، حذف |
| المكاتب | عرض، توثيق، إلغاء توثيق، طلبات الترقية |
| مزودي الخدمات | عرض، توثيق، إلغاء توثيق |
| الخطط والاشتراكات | إدارة كاملة للخطط، الميزات، والخصومات |
| الحسابات المحاسبية | عرض، إنشاء، تعديل، حذف، ترحيل القيود |

### نظام ترقية الحساب إلى مكتب عقاري
- يقدم المستخدم **طلب ترقية (Upgrade Request)** مرفقاً برخصة مزاولة المهنة وسجل تجاري.
- يراجع المشرف الطلب ويقبله أو يرفضه مع إبداء سبب الرفض.
- بعد القبول، يصبح المستخدم **مكتباً موثقاً (Verified Office)** يظهر عليه شارة التوثيق.

### إحصائيات الناشر
- عدد العقارات المنشورة.
- عدد المشاهدات الكلي.
- العقارات المتفاعل معها (المفضلة والمعاينات).
- تقارير تحليلية شهرية للأداء.

### تقييمات المكاتب
- يمكن للمستخدمين تقييم المكاتب العقارية (1-5 نجوم) مع تعليق.
- يُحسب متوسط التقييمات ويظهر في الملف الشخصي للمكتب.

## 🏘️ إدارة العقارات (RealEstate)

### بيانات العقار الكاملة
كل عقار يحتوي على بيانات شاملة:
- **الاسم** و**الوصف** التفصيلي.
- **النوع:** شقة، منزل، فيلا، أرض، تجاري، مكتب، مستودع، أخرى.
- **الغرض من العقد:** بيع أو إيجار.
- **الدولة** و**المدينة** (مرتبطة بجداول الدول والمدن).
- **الإحداثيات الجغرافية:** خط الطول وخط العرض للعرض على الخرائط.
- **الغرف، الحمامات، المساحة** (بالمتر المربع).
- **السعر** و**العملة**.
- **معلومات تفصيلية** إضافية (نص حر).
- مكتبة صور: **صورة رئيسية** ومعرض صور **Gallery** مع معالجة تلقائية للأحجام.
- **نوع الناشر** (فرد / مكتب عقاري).

### حالات العقار
يمر العقار بعدة حالات خلال دورة حياته:
```
مسودة ← قيد الانتظار ← قيد المعاينة ← مقبول ← مباع / مؤرشَف
                      ← مرفوض
                      ← معلق
```

- **مسودة (Draft):** لم ينشر بعد.
- **قيد الانتظار (Pending):** بانتظار مراجعة الإدارة (اختياري).
- **قيد المعاينة (Under Inspection):** يخضع لمعاينة ميدانية.
- **مقبول (Approved):** منشور وظاهر للعموم.
- **مرفوض (Rejected):** مرفوض مع سبب الرفض.
- **معلق (Suspended):** مخالف أو قيد المراجعة.
- **مباع (Sold):** تم بيعه.
- **مؤرشَف (Archived):** لم يعد معروضاً.

### المعاينة الميدانية للعقارات (Physical Inspection)
- يمكن طلب معاينة ميدانية للعقار للتحقق من مطابقته للوصف.
- تُسجل نتيجة المعاينة (درجة من 1-100) وتقرير المعاينة.
- يظهر وسم **"تمت معاينته"** على العقارات الموثقة ميدانياً.

### تصفح العقارات (للمستخدمين)
- عرض العقارات **المقبولة** فقط مع إمكانيات تصفية متقدمة:
  - البحث بالاسم أو الوصف.
  - تصفية حسب النوع (شقة، فيلا...)، الغرض (بيع، إيجار)، الدولة، المدينة.
  - تصفية حسب السعر (من - إلى).
  - تصفية حسب عدد الغرف والحمامات والمساحة.
  - تصفية حسب نوع الناشر (فرد / مكتب).
- الترتيب حسب: السعر (تصاعدي/تنازلي)، تاريخ الإضافة، عدد المشاهدات.
- خاصية **عشوائي**: عرض مجموعة عقارات عشوائية للاكتشاف.
- التفاصيل الكاملة لكل عقار مع صوره.

### لوحة تحكم الناشر
- **عرض عقاراتي:** قائمة بكل عقارات الناشر مع إحصائيات كل عقار.
- **إضافة عقار:** مع رفع الصور (رئيسية + معرض).
- **إضافة عقار مع مصور:** طلب خدمة تصوير للعقار.
- **تعديل العقار:** تحديث البيانات والصور.
- **حذف العقار:** حذف ناعم (Soft Delete).
- **إدارة حالة العقار:** تغيير حالة العقار يدوياً.

### نظام المفضلة (Loved/Favorites)
- يمكن للمستخدمين إضافة العقارات إلى المفضلة بنقرة واحدة.
- تظهر العقارات المفضلة في حساب المستخدم.
- يُعرف المستخدم إذا كان العقار في مفضلته مسبقاً عند التصفح.

### عداد المشاهدات
- يُسجل كل دخول على صفحة العقار كمشاهدة.
- عداد المشاهدات يظهر في لوحة تحكم الناشر.

## 🎯 الإعلانات والنظام الدعائي (Ads)

النظام الإعلاني من أهم مكونات المنصة، ويقدم مستويين من الإعلانات:

### المجموعات الإعلانية (Ad Groups)
- تجميع الإعلانات في مجموعات لتسهيل الإدارة.
- كل مجموعة لها اسم، وصف، وحالة (نشطة/غير نشطة).
- إمكانية **أرشفة** واستعادة المجموعات.
- تعيين **إعلان افتراضي** لكل مجموعة (يُعرض عند عدم وجود إعلانات نشطة).

### الإعلانات العادية (Banner Ads)
- إنشاء إعلانات **بنر** مع عنوان ووصف ورابط خارجي.
- وسائط متعددة: **صورة** أو **فيديو** مع ترتيب عرض متعدد.
- ربط الإعلان بعقار محدد في المنصة.
- حالة الإعلان: مسودة، نشط، متوقف، مؤرشف.
- تاريخ بداية ونهاية صلاحية الإعلان.
- إمكانية أرشفة واستعادة الإعلانات.

### الإعلانات الممولة (Sponsored Ads)
الإعلانات الممولة هي إعلانات مدفوعة تمنح العقار ظهوراً مميزاً. نظام تسعير متكامل:

| مستوى الإعلان | 7 أيام | 14 يوم | 30 يوم |
|---------------|--------|--------|--------|
| أساسي (Basic) | $4.99 | $8.99 | $14.99 |
| قياسي (Standard) | $9.99 | $17.99 | $29.99 |
| مميز (Premium) | $19.99 | $34.99 | $59.99 |

- الدفع عبر **Stripe** أو من **رصيد المحفظة** (Ledger).
- العرض للأجهزة حسب **نظام التناوب الموزون (Weighted Rotation)** — المستويات الأعلى تظهر أكثر.
- إمكانية إلغاء الإعلان الممول مع استرداد المبلغ المتبقي.
- عرض الإعلانات الممولة النشطة للعموم.

### تتبع الإعلانات (Ad Tracking)
- **تسجيل المشاهدات (Views):** عدد مرات ظهور الإعلان.
- **تسجيل الزيارات (Visits):** عدد مرات النقر على الإعلان.
- حساب **نسبة النقر إلى الظهور (CTR)**.
- تخزين عنوان IP ووكيل المستخدم للتحليل.

### تحليلات الإعلانات (Ad Analytics)
- **لوحة تحليلات عامة:** إجمالي المشاهدات، الزيارات، نسبة النقر.
- **تحليلات لكل مجموعة إعلانية.**
- **تحليلات لكل إعلان بشكل منفصل.**
- **تقارير بيانية** حسب الفترة الزمنية (يومي، أسبوعي، شهري).
- **تصدير التقارير** (تصدير البيانات للتحليل الخارجي).

### عرض الإعلانات للعموم
- Endpoints مخصصة لعرض الإعلانات في الواجهة الأمامية.
- دعم عرض إعلان منفرد، مجموعة إعلانات، أو كل الإعلانات المتاحة.
- تصفية الإعلانات حسب التاريخ والصلاحية تلقائياً.

## 📅 المعاينات والحجوزات (Property Viewings)

نظام متكامل لإدارة مواعيد معاينة العقارات:

### حجز معاينة
- أي مستخدم يمكنه حجز موعد لمعاينة عقار.
- تحديد **موعد المعاينة** و**المدة** (افتراضياً 30 دقيقة) و**فترة فاصلة** (Buffer) بين المواعيد (افتراضياً 15 دقيقة).
- أنواع المعاينات:
  - **شخصية (In-Person):** زيارة العقار فعلياً.
  - **افتراضية (Virtual):** عبر مكالمة فيديو.
  - **البيت المفتوح (Open House):** معاينة جماعية.
- تحديد الحد الأقصى لعدد الحضور (لنوع Open House).
- تسجيل اسم ورقم هاتف جهة الاتصال.

### دورة حياة المعاينة
```
قيد الانتظار ← مؤكد ← مكتمل
   ↓           ↓
  ملغى      مُعاد جدولته
              ↓
           لم يحضر
```

### لوحة تحكم المعاينات
- **قائمة المعاينات:** مع فلترة حسب الحالة والنوع والتاريخ.
- **معايناتي (My Viewings):** المواعيد الخاصة بالمستخدم الحالي.
- **جدول الوكيل (Agent Schedule):** مواعيد الوكيل العقاري.
- **روزنامة (Calendar):** عرض تقويمي للمواعيد مع إمكانية التصفية حسب الفترة.

### إجراءات المعاينة
- **تأكيد (Confirm):** تأكيد الموعد من قبل الوكيل.
- **إعادة جدولة (Reschedule):** تغيير موعد المعاينة.
- **إلغاء (Cancel):** إلغاء الموعد مع ذكر السبب.
- **إكمال (Complete):** إنهاء المعاينة بنجاح وإضافة ملاحظات الوكيل.
- **لم يحضر (No Show):** تسجيل غياب العميل عن الموعد.

## 💬 المحادثات والتواصل (Communication)

### المحادثات الفورية (Chat)
- **غرف محادثة (Chat Rooms):**
  - خاصة (Private): بين مستخدمين اثنين.
  - جماعية (Group): لأكثر من مستخدمين.
- ربط غرفة المحادثة بعقار معين.
- إدارة المشاركين في الغرفة (انضمام، وقت آخر قراءة).

### الرسائل
- **أنواع الرسائل:**
  - **نصية (Text):** رسائل نصية (حد أقصى 5000 حرف).
  - **صورة (Image):** إرسال الصور.
  - **ملف (File):** إرسال الملفات (حد أقصى 10 ميجابايت).
- **الرد على رسالة (Reply):** إمكانية الرد على رسالة محددة.
- **حذف الرسائل** (حذف ناعم).
- **مؤشر القراءة (Read Receipt):** معرفة وقت قراءة الرسالة.
- **عداد الرسائل غير المقروءة** لكل غرفة.

### مؤشر الكتابة (Typing Indicator)
- إشعار فوري عند بدء الطرف الآخر بالكتابة (مع تحديد معدل 1 إشعار/ثانية لتجنب الازدحام).

### المحادثات العقارية (Property Inquiry)
- يمكن للمستخدم بدء محادثة تلقائياً مع ناشر العقار من صفحة العقار.
- نوع خاص من المحادثات باسم `property_inquiry` مرتبطة بالعقار.

### الإشعارات (Notifications)

#### أنواع الإشعارات
| النوع | الوصف |
|-------|-------|
| رسالة جديدة (New Message) | عند استلام رسالة جديدة في المحادثة |
| عرض جديد (New Offer) | عند استلام عرض سعر على عقار |
| تحديث عقار (Property Update) | عند تغيير حالة عقار في المفضلة |
| تأكيد حجز (Booking Confirmed) | عند تأكيد موعد معاينة |
| تنبيه إداري (Admin Alert) | تنبيهات للمشرفين |
| انتهاء اشتراك (Subscription Expiring) | تنبيه قبل انتهاء الاشتراك |

#### إدارة الإشعارات
- **قائمة الإشعارات** مع إمكانية التصفح.
- **عداد الإشعارات غير المقروءة** (مع تحديد معدل الطلب).
- **تعليم إشعار كمقروء** (إشعار واحد أو الكل).
- **حذف الإشعارات**.

#### تفضيلات الإشعارات
- لكل مستخدم إمكانية تفعيل/تعطيل قنوات الإشعارات:
  - **FCM:** إشعارات الجوال (Android/iOS/Web).
  - **Pusher:** إشعارات الوقت الفعلي داخل المتصفح.
  - **Email:** إشعارات البريد الإلكتروني.

#### قنوات البث (Broadcasting Channels)
- `user.{id}`: قناة خاصة بالمستخدم.
- `chat.{roomId}`: قناة غرفة المحادثة.
- `property.{propertyId}`: قناة تحديثات العقار.

### إشعارات الجوال (FCM - Firebase Cloud Messaging)
- تسجيل **FCM Token** لكل جهاز (Android/iOS/Web).
- إلغاء تسجيل الرمز (Token Revocation).
- تنظيف الرموز منتهية الصلاحية تلقائياً (via Scheduler).
- دعم إرسال الإشعارات لمستخدم واحد، مجموعة مستخدمين، أو لقناة Topic.
- نظام أولويات: عالية (High) للإشعارات العاجلة، عادية (Normal).

### التواجد (User Presence)
- معرفة حالة المستخدم (متصل/غير متصل) عبر Redis.
- تحديث تلقائي لحالة التواجد.

## 🔧 مزودي الخدمات (Service Provider)

### التسجيل كمزود خدمة
- المستخدم يطور حسابه إلى **مزود خدمة** بإنشاء ملف شخصي احترافي:
  - **نوع الخدمة:** مصور، محامي، مفتش/مثمن، مسوق، أخرى.
  - **الخبرة** (بالسنوات) و**نبذة تعريفية**.
  - **رقم الترخيص المهني** (اختياري).
  - **نظام التسعير:** ثابت، بالساعة، قابل للتفاوض.
  - **السعر لكل مهمة** (اختياري).
  - **مناطق التغطية:** اختيار المدن التي يخدمها.
- توثيق مزود الخدمة من قبل الإدارة بعد المراجعة.
- إمكانية تفعيل/تعطيل التوفر للعمل.

### أنواع الخدمات
| النوع | الوصف |
|-------|-------|
| تصوير (Photography) | تصوير العقارات بشكل احترافي |
| تفتيش (Inspection) | معاينة وتقييم حالة العقار |
| قانوني (Legal) | استشارات وإجراءات قانونية |
| تسويق (Marketing) | تسويق العقارات وترويجها |

### طلبات الخدمة (Service Requests)
- **العميل:** ينشئ طلب خدمة (يحدد نوع الخدمة، العقار، الموعد، ملاحظات).
- **مزود الخدمة:** يستعرض الطلبات ويقبل أو يرفض.
- بعد القبول، يبدأ العمل ويُكمل المهمة.
- **المهام الجزئية (Tasks):** كل طلب خدمة يحتوي على مهام:
  - رفع صور (Photo Upload).
  - قائمة تدقيق (Checklist).
  - تقرير (Report).
  - تحقق (Verify).

### دورة حياة طلب الخدمة
```
قيد الانتظار ← مقبول ← قيد التنفيذ ← مكتمل
     ↓           ↓
   مرفوض       ملغي
```

### الفوترة لمزودي الخدمات (Provider Billing)
- **رصيد مزود الخدمة:** يظهر الرصيد الحالي والأرباح.
- **تسوية المدفوعات:** عند اكتمال الخدمة، تُحسب:
  - المبلغ الإجمالي.
  - عمولة المنصة (Platform Fee) — نسبة قابلة للتكوين.
  - صافي أرباح مزود الخدمة.
- **طلب سحب (Withdraw):** يمكن لمزود الخدمة طلب سحب أرباحه.

### إدارة العمولات
- النظام يدعم تكوين نسبة العمولة لكل نوع خدمة (ثابتة أو نسبة مئوية) عبر `ServiceCommissionConfig`.

### نظام الخصومات والكوبونات
- إنشاء **أكواد خصم (Coupons)** بنوعين:
  - **نسبة مئوية (Percentage).**
  - **قيمة ثابتة (Fixed).**
- ربط الكوبون بخطة محددة أو كل الخطط.
- تحديد **الحد الأقصى للاستخدام** و**تاريخ الانتهاء**.
- عداد الاستخدامات (يتزايد مع كل استخدام).
- **التحقق من صلاحية الكوبون** قبل الدفع.

### الدفع عبر Stripe
- **إنشاء جلسة دفع (Checkout Session):** يختار المستخدم الخطة والكوبون (إن وجد)، ويُرسل إلى بوابة دفع Stripe.
- **Webhook متكامل:** استقبال أحداث Stripe (نجاح الدفع، فشل، استرداد...) وتحديث حالة الاشتراك.
- تسجيل **جميع أحداث Stripe** الواردة في قاعدة البيانات للتدقيق.
- خيارات الدفع: **بطاقة ائتمان** أو من **رصيد المحفظة** الداخلية.

### دورة حياة الاشتراك
```
قيد الانتظار ← نشط ← منتهي
                ↓
              ملغي
```

### إدارة الاشتراكات
- **اشتراكي الحالي:** عرض الاشتراك النشط مع الميزات المتاحة.
- **سجل الاشتراكات:** تاريخ الاشتراكات السابقة.
- **إلغاء الاشتراك:** إلغاء الاشتراك الحالي (مع استمرار الميزات حتى نهاية المدة).
- **التحقق من الميزات:** API للتحقق من توفر ميزة معينة للمستخدم الحالي.
- **سجل تغييرات الحالة (Status Logs):** تتبع كل تغيير في حالة الاشتراك.
- **أوامر مجدولة (Scheduled Commands):**
  - `subscription:expire`: إنهاء الاشتراكات المنتهية تلقائياً.
  - `subscription:notify-expiring`: إرسال تنبيهات قبل انتهاء الاشتراك بـ 3 أيام.

## 📊 النظام المحاسبي (Ledger)

نظام محاسبي مزدوج القيد (Double-Entry Ledger) كامل داخل المنصة:

### شجرة الحسابات (Chart of Accounts)
منظمة وفق المعايير المحاسبية:

```
الأصول (Assets)
  ├── الأصول المتداولة
  │   ├── النقدية
  │   ├── البنوك
  │   └── الذمم المدينة
  └── الأصول الثابتة
      ├── المباني
      └── المركبات

الالتزامات (Liabilities)
  ├── الالتزامات المتداولة
  │   ├── الذمم الدائنة
  │   ├── الرواتب المستحقة
  │   └── أرصدة المستخدمين
  └── الالتزامات طويلة الأجل
      └── القروض

حقوق الملكية (Equity)
  ├── رأس المال
  ├── الأرباح المحتجزة
  └── صافي الدخل / الخسارة

الإيرادات (Revenue)
  ├── إيرادات الاشتراكات
  ├── إيرادات الإعلانات
  ├── إيرادات الخدمات
  ├── إيرادات العمولات
  └── إيرادات أخرى

المصروفات (Expenses)
  ├── الرواتب والأجور
  ├── الإيجارات
  ├── المرافق
  ├── التسويق
  ├── رسوم المنصة
  └── مصروفات أخرى
```

### أنواع الحسابات
| النوع | الوصف |
|-------|-------|
| رصيد مستخدم (User Balance) | حساب افتراضي لكل مستخدم (محفظة) |
| إيرادات (Revenue) | حسابات الإيرادات |
| مقاصة (Clearing) | حسابات التسوية المؤقتة (مثل Stripe) |
| رسوم منصة (Platform Fee) | عمولات المنصة |
| التزامات (Liability) | الالتزامات |
| مصروفات (Expense) | المصروفات |

### القيود المحاسبية (Journal Entries)
- **إنشاء قيد:** مع رقم تسلسلي تلقائي، تاريخ القيد، وصف، سطور مدينة ودائنة.
- **حالات القيد:** مسودة (Draft) ← مرحل (Posted) ← معكوس (Reversed).
- **ترحيل القيد (Post):** عند الترحيل، تُسجل القيود في ledger_account_entries ويتحدّث رصيد الحساب.
- **ميزان المراجعة (Trial Balance):** تقرير محاسبي بمجاميع الأرصدة المدينة والدائنة لكل حساب.

### السجلات المحاسبية (Ledger Entries)
- كل حركة مالية تُسجل كـ **Account Entry** برقم دفعة (Batch ID).
- يحتوي على: نوع القيد (مدين/دائن)، المبلغ، الرصيد بعد الحركة، العملة.
- **مفتاح منع الازدواج (Idempotency Key):** لمنع تكرار نفس الحركة.
- إمكانية ربط الحركة المالية بأي كيان في النظام (عبر Morph Reference).

### عمليات مالية جاهزة
- **تحويل (Transfer):** تحويل مبلغ من حساب إلى آخر (مقاصة تلقائية).
- **إيداع (Credit):** إضافة رصيد إلى حساب.
- **خصم (Debit):** خصم من حساب.
- **حجز (Hold):** حجز جزء من الرصيد (غير قابل للسحب).
- **تحرير المحجوز (Release Hold):** إعادة الرصيد المحجوز.

### المحفظة الإلكترونية (User Balance)
- كل مستخدم لديه حساب محفظة (User Balance Account) مرتبط بحسابه.
- يمكنه الاطلاع على:
  - **الرصيد الحالي (Balance).**
  - **الرصيد المتاح (Available Balance):** الرصيد مطروحاً منه المحجوز.
  - **كشف حساب (Statement):** سجل بكل الحركات المالية.

### إدارة الرواتب (Payroll)
- إعداد **جدول رواتب** لمزودي الخدمات:
  - **شهري (Monthly):** راتب ثابت شهري.
  - **بالمهمة (Per Task):** أجر عن كل مهمة مكتملة.
  - **كلاهما (Both):** راتب أساسي + أجر عن كل مهمة.
- **تنفيذ دورة الرواتب (Run Payroll):** حساب المستحقات لكل مزود خدمة وإنشاء دفعات.
- **سجل الدفعات:** متابعة حالة كل دفعة (معلقة، مدفوعة، فاشلة).
- عند الدفع، يُنشأ قيد محاسبي تلقائي.

## 🔄 سير العمل المتكامل — مثال

### سيناريو: مستخدم يبحث عن شقة ويشتريها

1. **المستخدم** يتصفح العقارات عبر `GET /api/properties/browse` مع فلترة (نوع: شقة، بيع، مدينة: الرياض، السعر).
2. يضيف عقاراً للمفضلة عبر `POST /api/dashboard/properties/{id}/favorite`.
3. يبدأ محادثة مع الناشر عبر `POST /api/chat/rooms` (ترتبط تلقائياً بالعقار).
4. يحجز موعد معاينة عبر `POST /api/dashboard/viewings`.
5. يستلم **إشعار تأكيد الحجز** (FCM على الجوال + Pusher في المتصفح + في قاعدة البيانات).
6. **الناشر** (مكتب عقاري) يشاهد المعاينة في الروزنامة ويؤكدها.
7. بعد المعاينة، **المستخدم** يشتري العقار.
8. **الناشر** يغير حالة العقار إلى "مباع" عبر `PATCH /api/dashboard/properties/{id}/status`.
9. المستخدم الذي أضاف العقار للمفضلة يستلم إشعاراً بتغير الحالة.
